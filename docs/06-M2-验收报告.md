## 3. 偏差与已知简化

1. **验真审核页**替代了原「后台审核」占位页，仅做房源验真；实名认证审核按计划在 M4 合并实现。
2. **在售调价**按「需店长审批」的业务规则直接拒绝（审批流属二期），提示先下架再改价。
3. **地图**为自绘 SVG 演示点位（不接高德 SDK、不申请 Key），区域标签取该区房源质心。
4. **税费估算**为前端简化规则（契税/增值税/个税），界面明确「仅供参考」。
5. **图片上传**限 PDF/JPG/PNG/WEBP ≤10MB，本地存储 `server/uploads/`（不入库）；真实 OSS/CDN 为 Demo 边界。
6. **重复测试数据**：API/E2E 用例会创建房源与小区，串行重复跑 `test:api` 需先 `db:reset`（`npm run verify` 已保证）。
7. **Bundle 体积**：因引入 ECharts 全量包，web 产物约 2.4MB（gzip 789KB），Demo 可接受，M5 可做按需加载。
