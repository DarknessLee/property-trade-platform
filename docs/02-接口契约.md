# 02 接口契约

> 状态：M1 冻结（2026-10-28）。字段级契约，M2/M3/M4 只做增量补充，不改已冻结字段；变更须记录 DECISIONS。
> Base URL：`/api`；数据格式 JSON；金额单位「元」（整数）；时间 ISO 8601。

## 1. 通用约定

### 1.1 认证
- 登录成功后返回 JWT；后续请求头 `Authorization: Bearer <token>`，有效期 12 小时。
- 角色：`buyer / seller / agent / store_manager / finance / admin`；后端按角色兜底，前端隐藏无权限菜单。

### 1.2 统一响应

```json
{ "code": 0, "message": "ok", "data": {} }
```

分页数据：`{ "items": [], "total": 0, "page": 1, "pageSize": 12 }`。

### 1.3 业务错误码

| code | HTTP | 含义 | 示例场景 |
| --- | --- | --- | --- |
| 0 | 200/201 | 成功 | — |
| 40001 | 400 | 参数校验失败 | 手机号格式错误、必填缺失 |
| 40101 | 401 | 未登录/令牌失效 | 无 token、token 过期或伪造 |
| 40102 | 401 | 登录失败 | 密码错误、验证码错误、账号禁用 |
| 40301 | 403 | 无权限 | 买方访问 B 端审核接口 |
| 40401 | 404 | 资源不存在 | 房源/合同 ID 不存在 |
| 40901 | 409 | 冲突/重复 | 编号重复、证件已被实名 |
| 42201 | 422 | 业务规则不满足 | 非法状态流转、带看时间冲突 |
| 50000 | 500 | 服务器错误 | 未捕获异常 |

### 1.4 枚举取值（字符串常量，与 `server/src/common/constants.ts` 一致）

| 领域 | 取值 |
| --- | --- |
| 房源状态 | `pending` 待审核 / `on_sale` 在售 / `signed` 已签约 / `offline` 已下架 |
| 验真状态 | `pending` 待验真 / `verified` 已验真 / `rejected` 验真驳回 |
| 合同状态 | `draft` 草稿 / `pending` 待签署 / `signed` 已签署 / `voided` 已作废 |
| 交易节点 | `sign` 面签 / `loan` 贷款审批 / `tax` 缴税 / `transfer` 过户 / `handover` 交房 |
| 节点状态 | `todo` 待办 / `doing` 进行中 / `done` 已完成 |
| 带看状态 | `pending` 待确认 / `confirmed` 已确认 / `done` 已完成 / `cancelled` 已取消 |
| 客户类型/评级 | `buyer` 买方 / `seller` 卖方；`A` / `B` / `C` |
| 支付类型 | `deposit` 定金 / `down_payment` 首付 / `balance` 尾款 / `commission` 佣金 |
| 支付状态 | `unpaid` 待支付 / `paid` 已支付 / `refunded` 已退款 |
| 实名状态 | `pending` / `approved` / `rejected` |

## 4. 状态机与业务规则

1. **房源**：`pending →(验真通过) on_sale →(签约) signed`；`on_sale → offline`；`signed` 不可回退/下架；`offline → on_sale` 需重新验真。
2. **合同**：`draft → pending →(双方签署) signed`；`draft/pending → voided`；签署后不可作废，只能走交易进度异常流程（Demo 不实现）。
3. **交易进度**：5 节点按 `sortOrder` 顺序推进；`done` 的节点数决定合同整体进度；前序未完成不可推进后序。
4. **带看冲突**：同一经纪人在同一时间段（前后 30 分钟缓冲）不可重复安排；取消/完成不占用时段。
5. **客户保护期**：保护期内该客户归属唯一经纪人；他人录入同手机号客户时不允许抢占（40901）。
6. **权限**：所有写接口后端校验角色 + 数据归属（本店/本人），前端仅隐藏入口。

## 5. 前端交互标识（testid 规范）

命名：`{区域}-{对象}-{动作}`，示例：`login-phone`、`btn-login`、`home-search`、`filter-district`、`listing-card-FC-901-000001`、`admin-page-title`、`btn-submit-realname`。
要求：可重复行使用 `data-testid` 前缀匹配（`[data-testid^="listing-card-"]`）；弹窗/抽屉以标题定位，不用 `.last()`。
