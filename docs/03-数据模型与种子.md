# 03 数据模型与种子

> 实现：`server/prisma/schema.prisma`（SQLite，PostgreSQL 兼容：枚举用字符串、JSON 用 TEXT）。
> 迁移：`server/prisma/migrations/`（init、user_agency、e1_enhancements）；初始化：`npm run db:reset`（migrate reset → seed → validate）。

## 3. 自校验（`server/prisma/validate.ts`，89 项）

- 数量偏差 ≤10%；
- 编码格式与唯一性（FC/HT/DK/KH/AP/ZX）；
- 手机号号段、身份证校验位与脱敏格式；
- 金额自洽（总价=round(单价×面积/1000)×1000；佣金=round(金额×费率)；合同金额=房源总价；定金>0）；
- 关系一致（房源机构=经纪人机构；带看同店；合同买卖方类型；合同机构=房源机构；经纪人已实名）；
- 状态机（状态取值、合同↔房源状态对应、面签节点完成）；
- 日期顺序（更新≥创建、签署≥上架、进度完成≥签署、带看实际≥预约、价格历史升序）；
- 唯一性（id、证件号、资金流水号、审批/咨询编号）；
- 价格历史（每条房源 ≥3 条、最后一条=当前挂牌价、价格与单价自洽）；
- 审批（状态/审批人/时间一致、通过记录价格=当前价）；
- 咨询（状态与回复内容一致、留言人≠经纪人）；
- 贷款/评估/监管/过户/佣金（E2）：编号格式、监管账户一对一、贷款 ≤ 合同金额、解冻合计与流水一致、佣金分摊合计 = 总额且比例 100%、已缴税有凭证、已付佣金有时间；
- 隐私（无真实品牌/个人信息，软删除默认 false）。

任一失败 → 退出码 1，`db:reset` 失败。

## 4. 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm run db:reset` | 重置库 + 迁移 + 种子 + 校验（幂等，可重复执行） |
| `npm run db:seed` | 仅重新灌数据（不删库） |
| `npm run db:validate` | 仅执行数据校验 |
| `npx prisma studio -w server` | 可视查看数据（可选） |
