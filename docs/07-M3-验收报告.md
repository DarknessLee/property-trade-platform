## 3. 偏差与已知简化

1. **电子签为 Mock**：签章图/CA/司法存证未实现，`esignNo` 与合同快照本地生成，UI 与 PDF 均标注「不具法律效力」。
2. **合同 PDF 依赖系统字体**：优先 `C:\Windows\Fonts\simhei.ttf`（存在则嵌入中文），跨机器部署可设 `CONTRACT_FONT_PATH`；缺失时输出英文摘要 PDF。
3. **合同金额规则**：Demo 强制等于挂牌总价（真实业务允许议价），用于演示金额一致性校验。
4. **签名方**：由经纪人/管理员或买卖本人点击「电子签署」模拟双方签署，未实现双人分步签署流程。
5. **带看冲突**：固定 30 分钟缓冲，未做跨门店/多经纪人联合资源校验。
6. **C 端预约**：需 buyer 已有客户档案（种子中 8 个买方账号已关联），否则提示联系经纪人建档。
7. **测试数据**：重复跑测试需 `db:reset`（`npm run verify` 已内置）；跨文件断言已按「在售+已签约=47」等不变量设计，但二次运行未重置仍会失败。
