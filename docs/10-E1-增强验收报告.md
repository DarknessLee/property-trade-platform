关键用例：

- 价格历史：每条非待审房源历史 ≥3 条、最后一条 = 当前挂牌价、价格与单价自洽、日期升序；C 端详情与 B 端详情均返回 `priceHistory`。
- 调价审批：经纪人仅可对本人/在售房源发起；同房源重复待审 409；已签约/下架 42201；经纪人不能审批自己提交的单；跨店审批 404；通过后房源总价/单价更新并新增 `approval` 来源价格历史，通知申请人；通过后重复审批 42201；驳回必填意见且不改价。
- 在线咨询：买方留言生成 `ZX` 单号并通知经纪人；经纪人收件箱可见并回复；重复回复 42201；其他经纪人 403；员工不能发起 C 端咨询；内容过短 400；买方「我的咨询」可见回复。
- 重复提示：同小区/面积±2㎡/同户型返回疑似重复房源（非阻断）；缺参返回空；无权限 403。

## 4. 已知简化

1. 价格历史为种子生成 + 审批写入，不含真实成交价（网签价/评估价口径留待二期看板）。
2. 审批流目前仅实现 `price_change` 一种类型，`ApprovalRequest.type` 预留 `key_handover/contract_void`，未开放入口。
3. 在线咨询为一问一答（每单一次回复），不支持下多轮对话/图片附件。
4. 重复提示仅"提示不阻断"，未做合并事务与跨门店查重。
5. 仍为 SQLite + Mock 第三方，电子签/支付/短信/实名/地图未接真实通道。
