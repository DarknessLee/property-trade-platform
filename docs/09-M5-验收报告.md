## 3. 偏差与已知简化（交付边界）

1. **软著材料不做**：按用户决策 D08，仅交付可运行 Demo 与工程文档；不生成 60 页源码/手册/申请表。
2. **全部外部系统 Mock**：电子签（无法律效力）、支付、短信、实名核验、地图、OSS、消息队列均为本地模拟。
3. **Demo 非功能边界**：未做并发/性能压测（5000 在线、QPS 1000）、99.9% 可用性、RPO/RTO、生产级 HTTPS/CI-CD。
4. **业务简化**：合同金额强制等于挂牌总价；电子签署为单步模拟双方签署；带看冲突仅按经纪人维度；审批流（调价/钥匙委托）属二期未实现。
5. **平台支持**：在 Windows + Node 24 下验收；SQLite 单机运行，schema 保持 PostgreSQL 兼容但未在 PG 环境实测。
6. **跨浏览器**：E2E 与截图仅 Chromium 1440×900；Safari/Firefox 与移动端宽度未做自动化验证（响应式栅格已配置）。
