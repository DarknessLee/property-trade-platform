## 3. 数据质量校验（种子初始化自动执行，任一失败即退出非 0）

- **编码规则**：房源编号 `FC-<城市码>-<6 位序号>`；合同编号 `HT<YYYY><6 位序号>`；带看单号 `DK<YYYYMMDD><4 位序号>`；全部唯一。
- **手机号**：合法号段（13x/15x/17x/18x/19x），11 位；展示脱敏 `138****8000`。
- **身份证**：18 位、校验位算法合法；库内脱敏存储，仅演示；不使用真实姓名组合。
- **金额自洽**：合同金额 = 成交单价 × 建筑面积（允许 ≤1 元取整差）；佣金 = 合同金额 × 佣金率（0.5%–3%）；房源总价 = 单价 × 面积。
- **关系一致**：房源业主/维护经纪人与机构归属一致；带看客户与经纪人同门店；合同关联房源状态合法（在售/已签约）。
- **状态机**：房源状态（待审核/在售/已签约/已下架）、合同签署状态（草稿/待签署/已签署/已作废）、交易进度节点（面签/贷款审批/缴税/过户/交房）取值合法且流转可达。
- **日期顺序**：房源上架 ≤ 带看 ≤ 合同签署 ≤ 进度节点时间；创建时间 ≤ 更新时间。
- **唯一性**：列表行数 = 唯一 id 数；证件号/登记编号不重复。
- **隐私**：虚构机构名（如「安家」「恒居」）、虚构小区名、虚构姓名；不使用真实品牌与真实个人信息。
- **数量**：按 D12 规模，偏差 ≤10%。

## 4. 每阶段门禁（通用）

构建零错误 / 类型检查通过；新阶段与全量旧回归全绿；数据校验通过；每角色允许+拒绝各 ≥1；文档（契约、报告、截图、索引）更新；提交并推送到远端，hash 记入报告。
