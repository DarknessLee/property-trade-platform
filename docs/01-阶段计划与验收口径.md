## 3. 数据质量校验（种子初始化自动执行，任一失败即退出非 0；当前 49 项）

- **编码规则**：房源 `FC-901-000001`；合同 `HT2026000001`；带看 `DK202610280001`；客户 `KH-000001`；全部唯一。
- **手机号**：合法号段（13x/15x/17x/18x/19x），11 位；展示脱敏。
- **身份证**：18 位、GB 11643 校验位合法；库内脱敏存储；不使用真实姓名组合。
- **金额自洽**：房源总价 = `round(单价×面积/1000)×1000`（千元取整）；合同金额 = 房源总价；佣金 = `round(合同金额×佣金率)`，佣金率 0.5%–3%；定金 > 0。
- **关系一致**：房源机构 = 经纪人机构；带看经纪人 = 房源维护人；带看客户与房源同门店；合同买卖方类型正确；合同机构 = 房源机构；经纪人均已实名。
- **状态机**：房源（pending/on_sale/signed/offline）、合同（draft/pending/signed/voided）、进度（todo/doing/done）；已签署合同 ↔ 已签约房源；草稿/待签署合同 ↔ 在售房源；已签署合同有面签完成节点。
- **日期顺序**：更新时间 ≥ 创建时间；合同签署 ≥ 房源上架；进度完成 ≥ 合同签署；带看实际 ≥ 预约。
- **唯一性**：列表行数 = 唯一 id 数；证件号/登记编号不重复；资金流水号唯一。
- **隐私**：虚构机构/小区/姓名；无真实品牌；软删除字段默认 false。
- **数量**：按 D12 规模，偏差 ≤10%。
