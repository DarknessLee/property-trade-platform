## 2. 验收命令（M1 冻结，冻结后变更写入 DECISIONS）

| 命令 | 用途 | 通过标准 |
| --- | --- | --- |
| `pnpm install` | 安装依赖 | 成功，无高危漏洞阻断 |
| `pnpm db:reset` | 重置库 + 迁移 + 种子 + 自校验 | 退出码 0；校验失败数 = 0 |
| `pnpm build` | 前后端构建 + 类型检查 | 0 错误（allow 警告） |
| `pnpm test:api` | API 验收（supertest/vitest） | 全绿；断言覆盖状态机正反路径 + 权限 |
| `pnpm test:e2e` | UI E2E（Playwright） | 全绿；页面 JS 异常视为失败 |
| `pnpm verify` | `build + test:api + test:e2e` 全量 | 全绿，退出码 0 |
| `pnpm screenshots` | 按角色/端批量截图 | 覆盖 6 角色核心页；无旧图；命名规范 |

## 3. 数据质量校验（种子初始化自动执行，任一失败即退出非 0）

- 必填/格式：手机号、身份证（脱敏展示）、备案编号、合同编号、房源编号规则。
- 关系：房源业主/维护经纪人与机构归属一致；带看客户与经纪人同门店；合同关联房源状态为在售/已签约。
- 金额：合同金额 = 成交单价 × 面积（允许 ≤1 元取整差）；佣金率在 0.5%–3% 区间；明细合计 = 总额。
- 状态机：合同签署状态、交易进度节点状态、房源状态取值合法且流转路径可达。
- 唯一性：列表行数 = 唯一 id 数；证件号/备案号不重复。
- 隐私：种子只用虚构姓名/手机号/证件号；品牌为虚构机构名。

## 4. 每阶段门禁（通用）

构建零错误 / 类型检查通过；新阶段与全量旧回归全绿；数据校验通过；每角色允许+拒绝各 ≥1；文档（契约、报告、截图、索引）更新；提交并记录 hash（推送待仓库地址就绪）。
