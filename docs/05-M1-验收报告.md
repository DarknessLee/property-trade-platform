## 3. 偏差与已知简化

1. **包管理**：使用 npm workspaces（pnpm 全局安装被 npm 新版 `allow-scripts` 策略阻断），脚本入口统一为 `npm run *`（D14）。
2. **测试转换**：Vitest 需 SWC 插件生成 Nest 装饰器元数据（`unplugin-swc`），已固化在 `server/vitest.config.ts`。
3. **B 端业务页**：M1 仅交付工作台骨架，房源/客户/带看/合同等页面显示「建设中 + 交付计划」，M2/M3 替换。
4. **C 端能力边界**：房源浏览/筛选（区域/价格/户型/关键词/排序）已可用；地图找房、税费估算、价格走势未实现（M2）。
5. **认证**：验证码登录为 Mock（固定 `123456`，不发真实短信）；微信扫码不做（A5）。
6. **第三方**：全部 Mock；无真实密钥；实名仅做校验位与脱敏，不调用核验接口。
7. **E2E 范围**：仅 Chromium 1440×900；Safari/Firefox/移动端响应式抽查待 M5。
8. **数据一致性修复**：房源总价按「千元取整」规则校验（`round(单价×面积/1000)×1000`），已在 `docs/01` §3 与 validate 中对齐。
