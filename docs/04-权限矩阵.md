# 04 权限矩阵

> 原则：**前端隐藏入口 + 后端强制校验**（每个角色至少 1 条允许 + 1 条拒绝用例，见 `server/test/api.spec.ts` 与后续阶段用例）。
> 数据范围：C 端看本人；经纪人看本人维护的房源/客户/带看/合同；店长看本店；财务看本店交易资金与业绩；管理员看全平台。

## 3. 关键校验点（后端兜底）

1. 未登录访问任意非公开接口 → `40101`；
2. 角色不符（如 buyer 调 B 端审核接口）→ `40301`；
3. 数据越权（经纪人改他店房源、财务改合同）→ `40301`；
4. 状态非法（已签约房源下架、跳过前序节点推进）→ `42201`；
5. 唯一冲突（重复编号/证件）→ `40901`。

## 4. 验收用例要求

- 每个角色：≥1 条允许请求 + ≥1 条拒绝请求（403/401）；
- 数据范围：经纪人 A 不能读取经纪人 B 的客户明细（店长/管理员除外）；
- 前端：无权限菜单不渲染（通过 `AdminLayout` 角色过滤），并用 E2E 断言管理员/经纪人菜单差异。
