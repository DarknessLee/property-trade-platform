## 4. 已知简化

1. 移动端为响应式适配，不是独立 H5 应用/小程序；B 端未做深度移动化（表格仍以桌面为主）。
2. 审批流仅支持「一级/两级」两种模式，未做可视化 BPM 设计器与多级会签。
3. 佣金规则为单条启用规则，未做按门店/时间版本化与审批生效流程。
4. 挂牌价走势基于价格历史月末快照，未接入真实成交/评估价指数。
5. 下拉下钻仅到小区层，未做楼盘/户型级钻取与地图联动。
