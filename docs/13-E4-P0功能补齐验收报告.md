## 4. 已知简化

1. 账号开通仅支持员工角色（经纪人/店长/财务/管理员），不开放 C 端注册；新建账号默认密码 123456。
2. 菜单权限为“可见/隐藏”级别，不做按钮级权限；管理员角色固定全菜单。
3. 匹配推荐为规则评分（预算/区域/标签），非协同过滤/机器学习。
4. 合同模板仅支持文本与占位符，未做富文本/条款库；补充条款不参与 PDF 排版（详情展示）。
5. 投诉审核仅一级管理员处理，未做客服工单流转/SLA。
6. 数据字典变更即时生效，未做缓存刷新与版本回滚。
