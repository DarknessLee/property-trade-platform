# 房产交易数字化协同平台（property-trade-platform）

面向房产交易的 B/S Web 协同平台 Demo（软著演示用），覆盖「房源—带看—签约—交易进度」全链路。

- 软件全称：房产交易数字化协同平台（V1.0，待确认）
- 产品形态：Web 前后端分离（React SPA + NestJS API），PC 优先、响应式兼容移动浏览器
- 当前阶段：**M0 立项（等待用户确认，未开始写业务代码）**
